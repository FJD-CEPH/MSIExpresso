MSIExpresso :
A tool for RNASeq analysis of transcriptional events related to microsatellite instability and MSI status determination.
Requirements:
- Perl
- BWA
- samtools
Running MSIExpresso:
<path to>/MSIExpresso.pl <configuration file> [updateStatus]
The configuration file contains all the information needed to run one sample analysis.
 Parameters are in the format key/value as follow : <parameter name>=<parameter value>
One parameter per line.
List of all parameters available:
Global parameters:
database dir: the location of the fasta database provided with MSIExpresso. (EG: <your path>/MSIExpresso/db).
ALL THE DATABASE FILES MUST BE DOWNLOADED AS AN ARCHIVE FROM box.com ADDRESS specified in the GitHub README.md.
output dir: the location for sample analysis output files (must be created before running MSIExpresso).
output files root: base name for each output file (e.g: the sample name)
path to bwa: path to bwa executable (version 0.7.15 or higher recommended) if not in the default path
bwa threads: number of threads for running bwa
path to samtools: path to samtools executable (version 1.3.1 or higher recommended) if not in the default path
Analysis parameters:
coding: performs coding microsatellites search (yes|no)
skipping: performs exon skipping search (yes|no)
intronic: performs intronic microsatellite search (yes|no)
read info files: generate log file of all reads counted for each analysis and the corresponding microsatellite genotype if available (yes|no)
minimum overlap length: for junctions and skipping counts, the minimum match length on one side of the junction
bam files: generate a bam file of matching reads for each alignment performed (yes|no)
fastq read1: fastq file for read1 (mandatory, may contain read1 and read2sequences  together)
fastq read2: fastq file for read2 (optional)
UTR panel: path to the file containing the list of the microsatellites tested for instability
MSI score cutoff:  for each microsatellite the minimum score to be considered as unstable (.75) increasing the value will give more stringency but leave to false negative, decreasing will increase the false positive rate
MSI-L cutoff/MSI-H cutoff: For a sample the percentage of unstable (MSI) microsatellites defining the sample status, below MSI-L cutoff the sample is MSS, between MSI-L and MSI-H the sample is MSI-L, above MSI-H cutoff sample is MSI-H.
Minimal expressed UTR: the minimum number of expressed microsatellites from the UTR panel to determine sample MSI status. Below this value, the sample has an unknown MSI status.
minimum coverage: the minimum number of reads mapping a microsatellite position/skipping event required to calculate the MSI score
minimum indel count: the minimum number of reads carrying a microsatellite sequence varying from the reference required to calculate the microsatellite MSI score.
Output files format:
1) MSI Status:
<SAMPLE NAME>.MSIstatus.cpunts.csv
MSI status (MSS|MSI-H) <percentage of instability> <number of unstable microsatellites> of <number of microsatellites found expressed>
List of microsatellites id and number of reads presenting instability
2) Coding microsatellites 
<SAMPLE_NAME>.CODING.counts.csv:
<microsatellite ID><base><length> <gene information><microsatellite observed sizes> 
Gene information: NM-gene name-exon/number total of exons type (coding|5’utr|3’utr)
Observed sizes: microsatellite relative size/count of reads from the longest deletion to the longest insertion. Normal reads have a “0” size, deletions have negative sizes, insertions positive sizes.
3) Exon skipping: 
<SAMPLE_NAME>.SKIPPING.counts.csv:
<Gene name><NM id><exon skipped><distance to the closest exon><total number of exons><microsatellite id> <number of skipping reads for exon N> <number junctions N-1/N reads> <number of junctions N/N+1 reads>
4) Intronic microsatellites:
<SAMPLE_NAME>.INTRONIC.counts.csv:
<microsatellite ID><base><length> <gene information><microsatellite observed sizes> 
Gene information: NM-gene name-exon/number total of exons
Observed sizes: microsatellite relative size/count of reads from the longest deletion to the longest insertion. Normal reads have a “0” size, deletions have negative sizes, insertions positive sizes.
Optional files:
Read files: <read name> <matching sequence id> <microsatellite relative size (if available)>
Sam files: the alignment line as given by bwa output.
